| Pacote | A partir de | Prazo | Páginas | Descrição |
|---|---|---|---|---|

**Não inclui:** login, base de dados, painel administrativo, loja online, inteligência artificial → "para isso, veja Lojas online e Sistemas web".
Pacote opcional de infraestrutura (publicação): referir como "Publicação, domínio e alojamento: orçamentados à parte" (sem valores).

## Secção 2 — Lojas online (3 níveis)
| Nível | A partir de | Prazo |
|---|---|---|
| **Loja Essencial** | 450.000 Kz | 30–60 dias |
| **Loja Profissional** | 650.000 Kz | sob orçamento |
| **Loja Avançada** | 900.000 Kz | sob orçamento |

**Essencial inclui:** catálogo, categorias, páginas de produto, páginas institucionais, finalização do pedido por WhatsApp, painel de gestão de produtos e categorias, gestão de imagens, base de dados e API. 
**Profissional acrescenta:** pesquisa e filtros, gestão de clientes e pedidos com estados, promoções, maior personalização do tema, relatórios básicos. 
**Avançada acrescenta:** possibilidade de pagamentos, integrações, cupões, notificações, analítica.
**Nota:** pagamento online, ERP e logística são orçamentados à parte.

## Secção 3 — Sistemas web (Full Stack)
| Nível | A partir de | Prazo |
|---|---|---|
| **MVP** | 600.000 Kz | 45–60 dias |
| **Sistema médio** | 900.000 Kz | 60–120 dias |
| **Sistema grande / Enterprise** | sob orçamento | 3 meses ou mais |

**MVP inclui:** autenticação, perfis de utilizador, painel administrativo, gestão de dados (CRUD), API, base de dados, validações, permissões básicas.
**Médio acrescenta:** vários módulos e perfis, relatórios, dashboards, notificações, integrações, auditoria, fluxos de trabalho.
**Grande:** ERP, sistemas de gestão empresarial, plataformas educativas, marketplaces. Desenvolvido por **fases**, com requisitos documentados e entregas por módulos.
**Como trabalhamos nos sistemas grandes (texto):** Descoberta → Requisitos → Arquitectura → Desenho UX/UI → Protótipo → MVP → Desenvolvimento por módulos → Testes → Segurança → Publicação → Homologação → Produção → Manutenção. (Mostrar como linha de tempo animada.)

## Secção 8 — FAQ (acordeão)
1. **Quanto tempo demora?** Depende do pacote (ver prazos). O prazo começa quando recebemos conteúdos e acessos.
2. **Posso alterar depois de entregue?** Incluímos 2 rondas de revisões durante o projecto; alterações adicionais são orçamentadas. Também temos planos de manutenção.
3. **O domínio e o alojamento estão incluídos?** Não incluídos no valor de desenvolvimento; orçamentamos à parte conforme as suas necessidades.
4. **Qual a diferença entre site e sistema web?** Um site apresenta a empresa; um sistema web tem login, base de dados e painel para gerir informação (utilizadores, pedidos, stocks…).
5. **Vendem na loja com pagamento online?** A loja base finaliza o pedido por WhatsApp; o pagamento online é uma extensão orçamentada à parte.
6. **Como peço um orçamento?** Por WhatsApp, email ou pelo formulário de contacto.
